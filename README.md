# linux-patches

Some patches for various projects in the Linux desktop ecosystem.

These patches were made for my own Linux laptop to resolve some quirks or fix bugs that haven't been fixed upstream.

> [!WARNING]
>
> Most of the patches were created with the help of generative AI due to my limited knowledge of OS development.
>
> I may not do line-by-line reviews of these patches, but I use them and they work fine on my machine.
>
> Use at your own risk.
